# ☀️ Weather Forecast API

An interactive Weather Forecast API built with **Streamlit** and **Python**, using **OpenWeatherMap API**.

---

## 🌍 Features
- Search real-time weather by city name
- Display temperature, humidity, wind speed, and weather conditions
- Show weather icon
- Fully dynamic using OpenWeatherMap API

---

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/weather-api.git
   cd weather-api
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Replace `YOUR_OPENWEATHERMAP_API_KEY` in `app.py` with your own API key from [OpenWeatherMap](https://openweathermap.org/api).
4. Run Streamlit:
   ```bash
   streamlit run app.py
   ```

---

## ☁️ Deploy on Streamlit Cloud
1. Push your repository to GitHub  
2. Go to [streamlit.io/cloud](https://streamlit.io/cloud)  
3. Select your repo and deploy — done!

---

## 🧠 Customization
- Change units from metric to imperial by modifying `units=metric` in `app.py` URL
- UI is fully customizable in `app.py`
